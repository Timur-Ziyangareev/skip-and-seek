# 🎬 Скипатель рекламы (и видео)

> **Если реклама не автоскипается — скипайте вручную на `D`.**

Браузерное расширение (Chrome / Edge / Brave и другие на Chromium), которое находит **любой** видеоплеер на **любом** сайте и перематывает видео:

- **A** — назад на 5 секунд
- **D** — вперёд на 5 секунд

## Возможности

- Определяет плеер автоматически: `<video>`, YouTube, Vimeo, Twitch, Netflix и т.д.
- Работает внутри `iframe` (в том числе встроенные плееры).
- Учитывает раскладку клавиатуры — работает и на русской раскладке (физические клавиши A и D).
- Не мешает набору текста: в полях ввода, поиска и чатах клавиши не перехватываются.
- Выбирает «главное» видео: приоритет у видимого, играющего и самого крупного плеера.
- Показывает всплывающую подсказку с новым временем (`+5 сек 01:23 / 03:45`).
- Автопропуск рекламы: авто-клик по кнопкам «Skip»/«Пропустить» и ускорение непропускаемой рекламы.
- В попапе можно выключить расширение или изменить шаг перемотки.

## Установка

1. Скачай папку `video-seek-extension`.
2. Открой в браузере `chrome://extensions` (в Edge — `edge://extensions`).
3. Включи **«Режим разработчика»** (переключатель справа сверху).
4. Нажми **«Загрузить распакованное расширение»** и выбери папку `video-seek-extension`.
5. Готово. Открой любое видео и жми `A` / `D`.

## Как это устроено

| Файл | Назначение |
|------|-----------|
| `manifest.json` | Манифест v3, права и точки входа |
| `content.js` | Скрипт на страницах: ищет `<video>` (включая shadow DOM), слушает клавиши, перематывает |
| `background.js` | Service worker: ретранслирует перемотку между фреймами, если фокус в другом фрейме |
| `ads.js` | Автопропуск рекламы: клик по «Skip», ускорение и приглушение рекламы |
| `popup.html` / `popup.js` | Настройки: вкл/выкл и шаг перемотки |
| `icons/` | Иконки расширения |

## Примечания

- На `chrome://...`, `about:` и страницах магазина расширения не работают (ограничение Chrome).
- Для видео с открытых файлов (`file://`) включи «Разрешить доступ к файловым URL» в настройках расширения.

## Реклама

Расширение не «взламывает» рекламу, а работает на уровне страницы. Оно определяет момент показа рекламы по нескольким сигналам и, пока реклама идёт, ускоряет её (по умолчанию 16×) и жмёт кнопки пропуска:

1. **Кнопки «Skip» / «Пропустить» / «Закрыть рекламу»** — кликаются автоматически, как только появляются (по классу, `aria-label` и тексту на разных языках).
2. **Классы плеера** — `vjs-ad-playing`, `vjs-ad-loading`, `ima-ad*`, `ad-showing`, `ad-playing`, `vast-*`, `ad-container` и т.п. (YouTube, videojs, Google IMA, JW Player, Plyr и др.).
3. **URL рекламы** — если `video.src` ведёт на рекламный домен (`doubleclick`, `googlesyndication`, `aniview`, `springserve`, `adserver` и т.п.).
4. **Надпись/таймер «Реклама»** — видимый текст «Реклама», «Пропустить рекламу», «Реклама закончится через N сек» рядом с видео.

Это покрывает плееры с amd.online (**CDN**, **Amedia**, **Kodik**), так как все они показывают VAST-прероллы по одной из этих схем, и «предсказывает» показ рекламы на других плеерах: ускорение включается, как только в DOM появляется любой из маркеров.

Ограничения: сайты периодически меняют разметку, поэтому эффективность может зависеть от версии плеера. Точный обход можно сделать только для каждого плеера отдельно по его живой разметке (нужна инспекция в браузере). Использование автопропуска может нарушать условия сервисов (ToS) отдельных сайтов — включай на свой страх и риск.
